# Support

- **A bug, a missed rule, or a feature:** open an issue with the matching
  form. Blank issues are off. A missed rule is a change the gate should flag
  and does not, such as a new suppression or a hook-bypass spelling.
- **A security problem:** `SECURITY.md` says what counts. Never a public issue.
- **A question about the design:** the feature form, naming the `DESIGN.md`
  section. If it argues for a change, it becomes an RFC (`docs/rfc/`).
- **A pull request:** `CONTRIBUTING.md` first.

There is no chat channel and no guaranteed response time. Issues are read.
